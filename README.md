# Sistema Bancário Java

Sistema bancário desenvolvido em Java com menu interativo no console.

## Funcionalidades
- Criar conta (Normal, Corrente ou Poupança)
- Depositar valor na conta
- Sacar valor com verificação de saldo
- Ver extrato com saldo atual
- Aplicar rendimento mensal (Conta Poupança)

## Tipos de conta
- **Conta Normal** — operações básicas de depósito e saque
- **Conta Corrente** — possui limite extra para saque além do saldo
- **Conta Poupança** — possui rendimento mensal configurável

## Tecnologias
- Java 21
- VS Code

## Conceitos aplicados
- Programação Orientada a Objetos (POO)
- Herança e Polimorfismo
- Exceções customizadas (SaldoInsuficienteException)
- throw e throws
- instanceof para verificação de tipo
- ArrayList e Coleções Java
- Scanner para entrada de dados
